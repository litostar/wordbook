# 单词本工作台

一个按「分类 + 日期」管理单词的网页应用。支持电脑浏览器打开，也支持微信小程序查看。

## 功能

- **分类管理**：听力 / 阅读 / 课外，可切换查看
- **按日期分组**：每天一个组，自动按时间倒序排列
- **快速添加**：单词、释义、备注、日期
- **编辑 / 删除 / 标记掌握**
- **搜索**：按单词、释义、备注搜索
- **导入 / 导出 JSON**：备份或迁移数据

## 电脑使用

直接用浏览器打开 `index.html` 即可。

数据默认保存在浏览器 `localStorage` 中，换浏览器或清缓存会丢失，建议定期导出 JSON 备份。

## 微信小程序实时查看

微信小程序要能「实时查看」，必须让数据存在**云端**而不是浏览器本地。推荐两种方案：

### 方案 A：网页部署到服务器 + 小程序 web-view（最简单）

1. 把 `index.html` 部署到任意公网静态托管（如 GitHub Pages / Vercel / Cloudflare Pages / 腾讯云 COS）。
2. 小程序后台配置「业务域名」。
3. 小程序里用 `<web-view src="你的网页链接"></web-view>` 打开。

优点：只维护一套网页代码。  
缺点：小程序 web-view 不支持个人小程序，需要企业/个体户资质。

### 方案 B：接入云端数据库（推荐，真正实时同步）

把数据存到云端数据库，网页和小程序同时读写同一份数据。

推荐服务：

| 服务 | 优点 | 缺点 |
|---|---|---|
| **Supabase** | 免费额度高，有 Realtime | 国内访问偶尔不稳定 |
| **LeanCloud** | 国内服务，小程序 SDK 完善 | 免费额度有限 |
| **微信小程序云开发** | 微信生态内，无需额外域名 | 需注册小程序并开通云开发 |

实现思路：

1. 在云端创建数据表 `words`，字段：`id, word, meaning, note, category, date, createdAt, mastered`。
2. 网页版把 `localStorage` 读写替换成云端 API 调用。
3. 微信小程序用同样 API 读取数据展示。

如果你确定要用某个方案，我可以继续帮你改造代码。
